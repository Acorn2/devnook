# DevNook v0.1.10

## 更新内容

- 修复 Vite 通过 `node_modules/.bin/vite` 启动、Python 通过 `-m` 启动项目内模块时，项目页漏报实际监听的问题。
- HTTP 就绪检查按监听地址核验进程组。使用 `localhost` 时支持 IPv4 和 IPv6，避免同端口上的其他进程导致服务误报就绪。
- 菜单栏快捷面板支持搜索和复制实际监听地址。服务列表按项目分组，项目页可直接筛选有服务监听的项目。
- 设置支持选择默认终端应用。运行日志可按输出流筛选，达到大小上限后滚动保留最新输出。服务配置支持复制，副本名称按 UTF-8 字节数截断。
- 托管服务的资源统计汇总整个进程组。Runner 仅在运行记录变化时写入数据库，服务就绪后使用独立的探活间隔。

## 安装与升级

按芯片选择 Apple Silicon 或 Intel Mac 的 DMG，将 DevNook 拖入 Applications。两个包均支持 macOS 12 或更高版本，采用 ad-hoc 签名，尚未通过 Apple 公证。安装前请核对下载来源及校验和。

升级前正常停止托管服务，退出旧版桌面并等待旧 Core 退出。启动新版后按原配置恢复服务，项目页会根据新的监听快照更新。

## English

- Fixed missing project listeners for Vite started via `node_modules/.bin/vite` and Python services started with a project-local `-m` entry.
- HTTP readiness checks verify ownership of each listener before probing. The `localhost` check supports IPv4 and IPv6.
- Search the menu bar panel, copy actual listening addresses, and filter projects with active service listeners. Managed services are grouped by project.
- Choose a preferred terminal, filter logs by stream, and duplicate service configurations. Bounded logs retain recent output.
- Managed resource metrics include the process group. The runner writes to the database when the run record changes and adjusts the probe interval after readiness.

Choose the Apple Silicon or Intel DMG for macOS 12 or later. Both are ad-hoc signed and lack Apple notarization. Verify the download and checksum before installation. To upgrade, stop managed services, quit the old desktop, and wait for its Core to exit before launching the new app and restoring your services.

## 校验 / Verify

将 DMG 和对应的校验文件放在同一目录。Place the DMG and its checksum file in the same directory.

```sh
# Apple Silicon
shasum -a 256 -c SHA256SUMS
# Intel Mac
shasum -a 256 -c SHA256SUMS-x86_64
```
