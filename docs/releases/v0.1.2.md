# DevNook v0.1.2

本次新增 macOS 菜单栏快捷面板，集中查看服务状态、实际端口与必要操作，并修正浏览器入口的显示依据。

## 更新内容

- **菜单栏快捷入口**：点击 N 图标查看运行中、需关注及收藏项目的服务。单服务项目合并一行，多服务才分组；340 逻辑单位宽、22px 服务行，内容过多时限高滚动，底部入口固定。
- **搜索与键盘操作**：超过 12 条自动显示搜索，也可用 ⌘F 按项目、服务或实际端口查找；方向键选择、Enter 进入详情、Escape 收起，上下箭头提示剩余内容。
- **减少刷新干扰**：同次展开保持高度、顺序、焦点与滚动位置。消失的条目立即禁用并保留原位置，下次展开重新计算。
- **准确的浏览器按钮**：仅复用近期在服务详情确认过、且当前监听与进程身份仍匹配的单一网页入口。API、未知或多入口不显示菜单栏地球图标，可进入详情读取或选择；不会因有端口就显示网页按钮，也不会展开时批量探测。
- **保留确认与控制边界**：启动 / 重启进入主窗口既有确认；托管服务可正常停止。外部与未知实例没有快捷停止，不增加强停或整项目启停。
- **窗口与主题**：关闭主窗口后保留菜单栏，可从 Dock 或面板恢复；退出 GUI 后已运行服务继续。隐藏窗口暂停轮询，面板与主窗口同步中英和浅暗偏好。
- **官网与文档**：增加中英文菜单栏介绍及四张使用虚构项目的实际界面演示图。

## 安装与升级

macOS 12+，根据芯片选择 Apple Silicon 或 Intel Mac DMG，打开后将 DevNook 拖入 Applications。更新前正常退出旧 GUI，避免出现多个菜单栏图标；不要覆盖仍在运行的应用文件。

本次保持 UDS v10 与 SQLite v3，不自动退出旧 Core、停止服务、安装 LaunchAgent 或修改 MCP 客户端。后台和服务生命周期独立于 GUI。

两个安装包均采用 **ad-hoc 签名，尚未完成 Developer ID 签名或 Apple 公证**。macOS 可能阻止首次打开；核对来源与 SHA-256 后参阅 [Apple 的应用安全打开说明](https://support.apple.com/en-us/102445)。

## English

This release adds a compact macOS menu bar panel for service status, actual ports, and everyday actions.

- Single-service projects use one row; multiple services receive project headings. The panel is 340 logical units wide with 22px rows, a bounded scrolling list, and a fixed footer.
- Search appears above 12 services, or with ⌘F. Match projects, services, or actual ports; use arrow keys, Enter for details, and Escape to close.
- Refreshes keep the current opening's height, order, focus, and scroll position. Missing entries immediately lose their controls while retaining their slot until the next opening.
- Browser icons require a recently confirmed single web entry from the service detail view, rechecked against current listener and process identity. APIs, unknown endpoints, and multiple entries stay in details. Opening the panel never probes every port.
- Start and restart retain the existing main-window confirmation. Managed services support graceful stop; external and unknown instances have no stop shortcut.
- Closing the main window keeps menu bar access; the Dock or panel restores it. Quitting the GUI leaves running services active. Hidden windows pause polling, and both windows share language and appearance preferences.

Choose the DMG for your Mac, quit the old GUI normally, then drag the new app into Applications. UDS v10 and SQLite v3 remain unchanged. The update does not terminate Core or services, install a LaunchAgent, or configure an MCP client.

Both installers target macOS 12+ and are **ad-hoc signed, without Developer ID signing or Apple notarization**. Check the source and checksum, then consult [Apple's guidance](https://support.apple.com/en-us/102445).

| Apple Silicon       | `DevNook_0.1.2_aarch64.dmg` |    4,874,171 |
| Intel Mac           | `DevNook_0.1.2_x64.dmg`     |    5,386,514 |

将 DMG 与对应校验文件放在同一目录。Download the DMG and its matching checksum file into the same directory.

```sh
# Apple Silicon
shasum -a 256 -c SHA256SUMS
# Intel Mac
shasum -a 256 -c SHA256SUMS-x86_64
```

## 验证范围 / Validation scope

- Apple Silicon 与 x86_64 / Rosetta 的 Release workspace 各 97 项测试通过，5 个既有内部 fixture 忽略；38 项界面测试通过。两份 DMG 均通过架构、版本、最低系统、签名完整性、镜像完整性与只读挂载后的逐文件一致性校验。两个测试矩阵均使用 Apple Python 3.9.6，不放宽就绪期限。
- 菜单栏界面通过隔离浏览器的真实 React 组件验证，包括长列表、搜索、键盘、状态变化与错误路径。本机锁屏阻断了本轮原生界面检查，未据此声称已完成原生菜单点击 / 失焦、多显示器或全屏 Space 验收；Intel 硬件与 macOS 12 真机仍需补充验证。
