# DevNook v0.1.4

修复端口悬浮提示遮挡页面的问题，并改善长启动命令的阅读与复制。

## 更新内容

- 移除端口列表整行的完整命令悬浮提示，Java classpath 等长参数不会在鼠标经过时铺满页面。
- 右侧启动命令默认最多显示四行；长命令支持展开、收起和区域内滚动，短命令不显示展开按钮。
- 复制始终取得完整命令，保留换行；成功和剪贴板失败均有反馈。
- 收起后回到命令开头，切换进程恢复折叠；窗口缩放会重新判断是否需要展开。
- 中英文官网补充说明，并更新四张浅暗主题端口页演示截图。截图只使用隔离演示数据。

## 安装与升级

macOS 12+，按芯片选择 Apple Silicon 或 Intel Mac DMG。正常退出旧 GUI 后，将新应用拖入 Applications，避免覆盖仍在运行的应用。退出 GUI 不会停止已经运行的服务。

本次沿用 UDS v10 与 SQLite v3，不修改 Core 服务控制、授权或持久化逻辑，不自动退出旧 Core 或停止服务。

两个安装包均为 **ad-hoc 签名，未完成 Developer ID 签名或 Apple 公证**。核对来源及 SHA-256；首次打开若被 macOS 阻止，请参阅 [Apple 的应用安全打开说明](https://support.apple.com/en-us/102445)。

## English

This release fixes oversized command tooltips in the port list and makes long launch commands easier to read and copy.

- Hovering a port no longer displays the full process command over the page.
- Commands in process details show up to four lines by default. Long commands can expand, collapse, and scroll within a bounded area; short commands need no expand button.
- Copy preserves the entire command and its line breaks, with feedback for success or clipboard failure.
- Collapsing returns to the command's beginning. Selecting another process resets the preview, and resizing updates whether expansion is needed.
- The bilingual website includes updated descriptions and four light / dark port screenshots using isolated demo data.

Choose the DMG for your Mac, quit the old GUI normally, and drag the new app into Applications. UDS v10, SQLite v3, Core service control, authorization, and persistence are unchanged. Existing Core and service processes are not terminated by this update.

Both installers require macOS 12+ and are **ad-hoc signed without Developer ID signing or Apple notarization**. Verify the source and checksum before following [Apple's guidance](https://support.apple.com/en-us/102445).

## 下载与校验 / Downloads and checksums

| 架构 / Architecture | DMG                         | 字节 / Bytes |
| ------------------- | --------------------------- | -----------: |
| Apple Silicon       | `DevNook_0.1.4_aarch64.dmg` |    4,874,700 |
| Intel Mac           | `DevNook_0.1.4_x64.dmg`     |    5,388,036 |

将 DMG 与对应校验文件放在同一目录。Download the DMG and matching checksum file into the same directory.

```sh
# Apple Silicon
shasum -a 256 -c SHA256SUMS
# Intel Mac
shasum -a 256 -c SHA256SUMS-x86_64
```
