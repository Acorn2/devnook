# DevNook v0.1.0

DevNook 的首个公开版本：在 macOS 上集中整理本地项目、启动开发服务、查看日志，并从占用端口定位进程和项目。

## 主要功能

- **项目库**：扫描后预览候选再导入，按分类、收藏、技术栈和监听状态查找项目，用常用编辑器打开工程。
- **服务与日志**：保存并复用启动配置，确认启动、停止或重启；查看就绪状态、实际监听端口和 stdout / stderr 历史日志。
- **端口排查**：搜索 TCP 端口、PID、命令或目录，区分托管服务与外部进程。外部停止需要身份核验和单独确认。
- **启动方案**：按依赖顺序等待服务就绪，复用已有运行；回滚或停止方案时只处理本次创建的实例。
- **桌面体验**：默认窗口 1280×800，支持浅色 / 暗色和简体中文 / English；首次按系统首选语言选择，支持手动切换。
- **CLI / MCP**：终端和可选 MCP 接入共用本机后台。MCP 默认只读，服务控制需要范围授权与对应确认。

关闭桌面窗口后，已经启动的服务与日志仍由独立本机后台维护。扫描、导入和保存配置都不会自动执行项目命令。

## 下载与安装

| 项目          | 要求 / 文件                                             |
| ------------- | ------------------------------------------------------- |
| 系统          | macOS 12 或更高版本                                     |
| Apple Silicon | `DevNook_0.1.0_aarch64.dmg`，4,695,106 字节（4.70 MB）  |
| Intel Mac     | `DevNook_0.1.0_x64.dmg`，5,182,582 字节（5.18 MB）      |
| 校验文件      | Apple Silicon：`SHA256SUMS`；Intel：`SHA256SUMS-x86_64` |
| 许可          | MIT                                                     |

1. 从本 Release 的 Assets 按芯片选择 DMG，打开后将 DevNook 拖入 Applications。
2. 打开应用，扫描并预览已有工程，再选择导入。
3. 进入项目服务页，核对启动建议或填写自己的命令，保存配置后确认执行。

**签名状态**：两个构建均采用 ad-hoc 签名，尚未完成 Developer ID 签名或 Apple 公证。macOS 可能阻止首次打开；核对下载来源与校验和后，可参阅 [Apple 的应用安全打开说明](https://support.apple.com/en-us/102445)。Intel 构建已通过 Apple Silicon 主机上的 x86_64 / Rosetta 隔离测试与真实窗口启动检查，Intel 与旧 macOS 真机仍需补充验证。本次没有 Windows 或 Linux 安装包。

## SHA-256

将所选 DMG 与对应校验文件放在同一目录，按架构执行：

```sh
shasum -a 256 -c SHA256SUMS
# Intel Mac
shasum -a 256 -c SHA256SUMS-x86_64
```

## English

The first public DevNook release brings local projects, development services, logs, and TCP port inspection into one macOS desktop workspace.

- Preview scanned projects before importing, organize them with categories and favorites, and open them in installed editors.
- Save launch configurations, confirm service actions, inspect readiness and actual listeners, and search stdout / stderr by run.
- Trace occupied ports to process commands, directories, and projects. External processes remain separate and require identity checks and confirmation before stopping.
- Prepare multiple services in dependency order, reuse existing runs, and roll back only instances created by the current startup plan.
- Use a 1280×800 default window, light / dark themes, and Simplified Chinese / English with system-language detection and manual switching.
- Query the same local backend through the CLI or optional MCP integration. MCP is read-only by default; control requires scoped authorization and confirmation.

Started services and logs continue after the desktop window closes. Scanning, importing, and saving configuration do not execute project commands.

**Download**: choose `DevNook_0.1.0_aarch64.dmg` (4.70 MB) for Apple Silicon or `DevNook_0.1.0_x64.dmg` (5.18 MB) for Intel Macs, both targeting macOS 12 or later. Open the DMG and drag DevNook into Applications. Download the matching `SHA256SUMS` (Apple Silicon) or `SHA256SUMS-x86_64` (Intel) and use its verification command above.

**Signing and validation**: both builds are ad-hoc signed and have not completed Developer ID signing or Apple notarization. macOS may block the first launch; see [Apple's guidance](https://support.apple.com/en-us/102445) after verifying the source and checksum. The Intel build has passed x86_64 / Rosetta integration tests and native window startup checks on an Apple Silicon host; Intel hardware and older macOS devices still need verification. Windows and Linux installers are not included.
