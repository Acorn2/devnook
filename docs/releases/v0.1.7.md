# DevNook v0.1.7

服务列表现在能单独显示识别到的 FastAPI 启动建议，不再把独立后端和根目录的其他启动方式混在一起。

## 更新内容

- DevNook 可从约定的 Python 入口识别明确的 FastAPI / Uvicorn 启动方式。能确认固定端口时，建议会预填端口和 TCP 就绪检查。启动建议与已保存配置分开显示和计数；扫描不会创建或启动服务，也不会猜测数据库依赖。
- 扫描结果可按导入状态筛选，也可在扫描弹窗中选用最近完成的扫描目录。
- 仅监听 IPv6 回环的网页服务，在同端口没有其他回环监听冲突时可显示 `localhost` 访问地址。
- [官网实操短片](https://acorn2.github.io/devnook/#demos)分别演示扫描导入、服务与日志、端口定位和按依赖启动。

## 安装与升级

按芯片选择 Apple Silicon 或 Intel Mac 的 DMG。两个包均以 macOS 12 为最低版本、采用 **ad-hoc 签名，未通过 Apple 公证**；macOS 首次打开时可能拦截。建议先核对下载来源和校验和，再安装。

替换已有应用前正常退出旧窗口。若新版窗口仍连着旧后台，先在方便中断开发时正常停止托管服务，再退出 DevNook 桌面、CLI 和 MCP 客户端，等旧后台闲置退出后打开新版。项目和已保存的服务配置会保留；只重开窗口不一定会切换后台。

## English

- DevNook recognizes an explicit FastAPI/Uvicorn entry point in supported Python layouts and suggests a fixed port and TCP readiness check when they can be determined. Suggestions appear separately from saved configurations. Scanning never starts or configures services and does not infer database dependencies.
- Filter scan results by import status and pick from recently scanned directories.
- Web services listening only on IPv6 loopback can use a `localhost` address when another loopback listener is not using the same port.
- The [quick demos](https://acorn2.github.io/devnook/en/#demos) cover importing, starting and reading logs, tracing ports, and running services in dependency order.

Choose the Apple Silicon or Intel DMG for macOS 12 or later. Both packages are **ad-hoc signed and not notarized by Apple**. To switch from an older Core, gracefully stop managed services when convenient, quit all DevNook clients, wait for the old Core to exit when idle, then open the new app. Your project and service configurations are preserved.

## 校验 / Verify

将 DMG 和对应的校验文件放在同一目录。Place the DMG and its checksum file in the same directory.

```sh
# Apple Silicon
shasum -a 256 -c SHA256SUMS
# Intel Mac
shasum -a 256 -c SHA256SUMS-x86_64
```
