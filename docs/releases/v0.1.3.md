# DevNook v0.1.3

本次更新颜色标签，让项目、服务和实际端口在不同页面中更容易对应，并更新中英文官网截图。

## 更新内容

- **项目配色保持一致**：项目图标、服务标记、实际端口与菜单栏端口使用稳定的项目配色，不随排序、筛选或语言切换改变。未关联项目保持中性；有限色板允许不同项目同色，名称与路径仍是识别依据。
- **技术栈彩色标签**：语言与常见框架采用固定色系，未知框架保留中性色。浅色、暗色分别提供文字、底色与边框。
- **状态颜色独立表达**：托管已就绪使用绿色，外部正在监听与运行未就绪使用青色，过渡与待核验使用琥珀，失败使用红色，已停止 / 未启动使用灰色空心点。状态文字全部保留，外部监听不等于已就绪。
- **端口与菜单栏**：实际端口使用浅底标签，来源保留“DevNook 托管 / 外部发现”文字。菜单栏仍为 340 逻辑单位宽、22px 单行；快照未知时不显示彩色实际端口。
- **官网更新**：替换中英、浅暗共 32 张应用演示截图，补充项目配色说明。所有截图使用隔离演示数据。

## 安装与升级

macOS 12+，按芯片选择 Apple Silicon 或 Intel Mac DMG。正常退出旧 GUI 后，将新应用拖入 Applications；不要覆盖仍在运行的应用文件。退出 GUI 不会停止已运行的服务。

本次保持 UDS v10 与 SQLite v3，不修改服务执行、授权或持久化逻辑，不自动退出旧 Core 或停止服务。

两个安装包均为 **ad-hoc 签名，未完成 Developer ID 签名或 Apple 公证**。macOS 可能阻止首次打开；核对来源与 SHA-256 后参阅 [Apple 的应用安全打开说明](https://support.apple.com/en-us/102445)。

## English

This release adds consistent project colors and colored technology and port labels, with updated bilingual website screenshots.

- Project icons, service markers, actual ports, and menu bar port labels share a stable project color across sorting, filtering, and language changes. Unassigned projects stay neutral. Colors may repeat; project names and paths remain the identifiers.
- Languages and common frameworks use colored labels with separate light and dark palettes. Unknown frameworks stay neutral.
- State colors remain independent: green for managed readiness, cyan for external listeners or running without readiness, amber for transitions or unverified identity, red for failures, and neutral hollow dots for stopped or unstarted configurations. State text is always retained.
- Actual ports use tinted labels; managed and external sources remain explicit. The menu panel keeps its 340-unit width and 22px rows. Unavailable port snapshots do not show colored actual-port labels.
- The website includes 32 updated light / dark screenshots in Chinese and English, all using isolated demo data.

Choose the DMG for your Mac, quit the old GUI normally, and drag the new app into Applications. UDS v10, SQLite v3, service control, authorization, and persistence remain unchanged. Existing Core and service processes are not terminated by this update.

Both installers require macOS 12+ and are **ad-hoc signed without Developer ID signing or Apple notarization**. Verify the source and checksum before following [Apple's guidance](https://support.apple.com/en-us/102445).

## 下载与校验 / Downloads and checksums

| 架构 / Architecture | DMG                         | 字节 / Bytes |
| ------------------- | --------------------------- | -----------: |
| Apple Silicon       | `DevNook_0.1.3_aarch64.dmg` |    4,874,808 |
| Intel Mac           | `DevNook_0.1.3_x64.dmg`     |    5,387,570 |

将 DMG 与对应校验文件放在同一目录。Download the DMG and matching checksum file into the same directory.

```sh
# Apple Silicon
shasum -a 256 -c SHA256SUMS
# Intel Mac
shasum -a 256 -c SHA256SUMS-x86_64
```
