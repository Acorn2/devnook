# DevNook v0.1.5

在服务列表中直接收藏项目，方便从正在使用的服务回到项目。

## 更新内容

- 服务配置、未保存的启动建议与已关联外部服务旁增加项目收藏星标。
- 同项目的所有星标、项目库与“已收藏”筛选同步；收藏操作保留当前服务选择与列表顺序。
- 支持键盘、中英文提示和浅暗主题；保存期间防止重复操作，失败保留原状态并显示错误，可重试。
- 收藏沿用已有项目记录；无法找到所属项目时不显示入口。

## 安装与升级

macOS 12+，按芯片选择 Apple Silicon 或 Intel Mac DMG。正常退出旧 GUI 后，将新应用拖入 Applications，避免覆盖仍在运行的应用。退出 GUI 不会停止已经运行的服务。

本次沿用 UDS v10 与 SQLite v3，收藏复用已有项目更新接口。两个安装包均为 **ad-hoc 签名，未完成 Developer ID 签名或 Apple 公证**。核对来源及 SHA-256；首次打开若被 macOS 阻止，请参阅 [Apple 的应用安全打开说明](https://support.apple.com/en-us/102445)。

## English

Favorite a project directly from its configured services, launch suggestions, or associated external services.

- Stars for the same project stay in sync with the project library and Favorites filter, preserving the current service selection and list order.
- Keyboard access, Chinese and English labels, and light and dark themes are supported. Duplicate saves are prevented; failures keep the previous state and allow retry.
- The action uses the existing project record. Services without a known project have no star.

Choose the DMG for your Mac, quit the old GUI normally, and drag the new app into Applications. UDS v10 and SQLite v3 are retained; project favorites use the existing update interface. Running Core and service processes are preserved.

Both installers require macOS 12+ and are **ad-hoc signed without Developer ID signing or Apple notarization**. Verify the source and checksum before following [Apple's guidance](https://support.apple.com/en-us/102445).

## 下载与校验 / Downloads and checksums

Download the DMG and matching checksum file into the same directory. 将 DMG 与对应校验文件放在同一目录。

```sh
# Apple Silicon
shasum -a 256 -c SHA256SUMS
# Intel Mac
shasum -a 256 -c SHA256SUMS-x86_64
```

- 38 项前端测试通过；收藏交互通过中英、浅暗及两种窗口尺寸共 8 个隔离浏览器场景。另测保存延迟 / 失败重试、键盘、即时语言切换、端口读取失败、项目记录缺失、启动建议与搜索筛选同步。
- Apple Silicon 与 x86_64 / Rosetta 的 Release workspace 各 97 项测试通过，5 个既有内部 fixture 忽略。测试使用 Apple Python 3.9.6，未修改测试或产品期限。
- 双架构 DMG 均通过版本、Mach-O 架构与最低系统、签名完整性、镜像完整性、Applications 链接、只读挂载逐文件一致性与校验和检查。
- 两种架构的原生应用在 Apple Silicon 主机上完成只读窗口启动检查，保留既有 Core、runner、服务配置与运行实例；Intel 验证通过 Rosetta。星标交互在隔离浏览器中验证，本轮未自动修改真实项目收藏；原生菜单栏交互、Intel 硬件与 macOS 12 真机未重新验收。
- 38 UI tests and 8 isolated browser scenarios passed, plus save / failure, keyboard, language, missing-data, suggestion, and search checks. Both Release workspaces passed 97 tests, with 5 existing fixtures ignored.
- Both disk images passed integrity, architecture, minimum-system, mounted-content, and checksum checks. Native window startup was checked on Apple Silicon, using Rosetta for Intel. Native star and menu interactions, Intel hardware, and macOS 12 devices were not revalidated.
