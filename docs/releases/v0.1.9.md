# DevNook v0.1.9

本次更新重点提升了运行态资源可见性、高频操作交互体验与端口排查降噪能力。

## 更新内容

- **实时性能指标监视**：基于 macOS 原生系统调用实时获取物理内存常驻集（RSS）与 CPU 累计运行时间，在服务卡片、详情头部及端口详情中直观透出。
- **高频操作直达与防误触**：左侧服务卡片启停采用微型操作胶囊（消除复选框误导）；服务详情头部常驻「打开网页」、「重启」、「停止」与「编辑配置」快捷操作。
- **日志可读化与智能吸附**：运行日志输出采用本地化秒级时间戳（如 `[15:23:40]`）；上滑翻看历史报错时智能保持视口位置，滚回底部自动恢复最新输出吸附跟随。
- **端口管理快捷分段降噪**：新增 `全部` / `DevNook 托管` / `项目关联` / `系统与未关联` 快捷分类标签，一键过滤 macOS 60+ 系统后台无用端口干扰。
- **代码架构解耦与轮询优化**：解耦核心服务页（抽离 `ServiceEditor` 与 `ServiceConfirmation` 组件），日志轮询引入引用缓存，大幅消除无谓重渲染与发热。

## 安装与升级

按芯片选择 Apple Silicon 或 Intel Mac 的 DMG，打开后将 DevNook 拖入 Applications。两个包均支持 macOS 12 或更高版本，采用 **ad-hoc 签名，尚未通过 Apple 公证**。首次打开可能被 macOS 拦截，安装前请核对下载来源和下方的校验和。

## English

- **Real-time resource monitoring**: Reads process physical memory (RSS) and accumulated CPU time via macOS kernel system calls, displayed in service cards, header, and port process details.
- **Quick action controls**: Service cards feature unmistakable mini action buttons; the service detail header keeps Open in Browser, Restart, Stop, and Edit Configuration 1-click accessible.
- **Readable logs & smart auto-scroll**: Stdout / stderr lines use localized readable timestamps (e.g. `[15:23:40]`); scrolling up to read stack traces keeps your view steady without being pulled to the bottom.
- **Port category segmented filter tabs**: Quick tabs for All, DevNook Managed, Project Associated, and System & Unassociated with real-time counters instantly filter out 60+ noisy macOS system daemons.
- **Component decoupling & render bailout**: Monolithic ServicesPage decoupled into ServiceEditor and ServiceConfirmation; run log polling uses memoized page comparison to eliminate redundant re-renders.

Choose the Apple Silicon or Intel DMG for macOS 12 or later. Open the DMG and drag DevNook into Applications. Both packages are **ad-hoc signed and not notarized by Apple**. macOS may block the first launch. Verify the download source and checksum before installing.

## 校验 / Verify

将 DMG 和对应的校验文件放在同一目录。Place the DMG and its checksum file in the same directory.

```sh
# Apple Silicon
shasum -a 256 -c SHA256SUMS
# Intel Mac
shasum -a 256 -c SHA256SUMS-x86_64
```
